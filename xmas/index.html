I'm attaching a photo of a handwritten sign-up sheet titled "State & Local Team — Christmas Card List". Each row has a name, a street address, and city / state / ZIP. Please turn it into contacts I can import into my phone.

1. Read every filled-in row. Skip blank or crossed-out rows. Don't guess: if a name, number or ZIP is hard to read, mark it with [?].
2. First, show me a table of what you read (name, street, city, state, ZIP) and list anything marked [?] so I can correct it.
3. Then create ONE vCard file (version 3.0) named state-local-christmas-card-list.vcf with one contact per row:
   - FN and N from the name as written. A couple ("Jane & John Smith") is one contact, last name Smith.
   - ADR;TYPE=HOME with street, city, state, ZIP, country USA.
   - CATEGORIES:State & Local Team Christmas Card List
   - NOTE:Christmas card list, State & Local team
