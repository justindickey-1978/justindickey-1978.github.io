Privacy Policy: Edmund Orchestration

Last updated: October 24, 2026

Edmund Orchestration is a personal tool operated by its owner for their own use only. It is not available to the public.

What it accesses

With the owner's authorization, the app reads the owner's own Gmail messages through Google's API to prepare a private daily briefing. It does not access any other person's Google account.

How data is used

Data is used only to produce the owner's briefing. It is stored only on the owner's own computer and is not sold, shared with third parties, or used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Use the support email shown on the app's Google consent screen.
